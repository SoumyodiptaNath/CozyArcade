# 🍵 Cozy Arcade

A collection of warm, minimalist mini-games built with pure HTML, CSS, and Vanilla JavaScript. Features synthesized Web Audio soundscapes and procedural gameplay with zero external dependencies.

🎮 **[Play Cozy Arcade Live](https://soumyodiptanath.github.io/CozyArcade/)**

---

## 🕹️ Included Games

* 🦔 **Mole Garden** (`cozy_mole_garden.html`) – Quick-reflex garden whacking game with smooth CSS creatures.
* 🍓 **Cozy Drop** (`cozy_drop.html`) – Shape-matching chute sorter with dynamic, creeping danger lines.
* 🚌 **Bus Express** (`cozy_bus_express.html`) – Continuous-steering snake runner with passenger boarding mechanics.
* 🗼 **Lighthouse Watch** (`cozy_lighthouse.html`) – Reflex timing game spotting pirate ships in a rotating light beam.

---

## ✨ Features

* **Zero Assets:** All sound effects, ambient lo-fi music, and art are generated procedurally via code and the Web Audio API.
* **Mobile Ready:** Touch-optimized controls with instant pointer event handling.
* **Persistent Stats:** High scores and theme preferences saved automatically via `localStorage`.
* **Cozy Themes:** Built-in Twilight (Dark) and Sunlight (Light) modes.
